# M6-2 Plan 3：web 画布投喂入口

> **For agentic workers:** REQUIRED SUB-SKILL: Use agent-harness:subagent-driven-development (recommended) or agent-harness:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在画布上选中节点后能投喂给已有任务；现场条显示注入次数；被注入节点有“已投喂”标记，已删除节点计入缺失。

**Architecture:** `InjectContextDialog` 复用现有选择与 `useCommand`；`CanvasPanel` 负责打开/关闭、默认目标任务和刷新；`toFlowNodes` 接收 `injectedNodeIds`，`NodeShell` 渲染文字徽标。现场布局仍只读。

**Tech Stack:** React 19、HeroUI v3、Tailwind 4、TanStack Query、Testing Library。

**Design sync:** 新增 UI 只使用 `DESIGN.md` token：`bg-surface`、`border-separator`、`text-muted`、`bg-accent/10`、`text-accent`。`已投喂` 必须同时有图标和文字，不能只靠颜色；Task 3 的组件测试验证。

**Commit strategy:** 每个 task 末尾提交；最后统一跑 `pnpm verify`。

**File structure:**

- `apps/web/src/features/canvas/InjectContextDialog.tsx`：投喂对话框。
- `apps/web/src/features/canvas/CanvasToolbar.tsx`：全局入口。
- `apps/web/src/features/canvas/TaskSceneBar.tsx`：现场入口与计数。
- `apps/web/src/features/canvas/CanvasPanel.tsx`：打开/关闭、刷新、注入节点集合。
- `apps/web/src/features/canvas/model.ts`：`injected` 字段。
- `apps/web/src/features/canvas/nodes/NodeShell.tsx` + 各节点：徽标。

```tsx
import { canInjectContext } from '@baton/core'
import type { Node, TaskSummary } from '@baton/protocol'
import { Button } from '@heroui/react/button'
import { Modal } from '@heroui/react/modal'
import { TextArea } from '@heroui/react/textarea'
import { useEffect, useMemo, useState } from 'react'
import { useCommand } from '../../lib/command-context'
import { nodeTitle } from './node-title'

export function InjectContextDialog({
  open,
  nodes,
  tasks,
  defaultTaskId,
  onOpenChange,
  onDone,
}: {
  open: boolean
  nodes: Node[]
  tasks: TaskSummary[]
  defaultTaskId: string | null
  onOpenChange: (open: boolean) => void
  onDone: () => void
}) {
  const send = useCommand()
  const injectable = useMemo(
    () =>
      tasks.filter(
        (task) =>
          canInjectContext({ status: task.status, waitingReason: task.waitingReason }).ok,
      ),
    [tasks],
  )
  const [taskId, setTaskId] = useState('')
  const [note, setNote] = useState('')
  const [error, setError] = useState<string | null>(null)
  const [pending, setPending] = useState(false)

  useEffect(() => {
    if (!open) return
    setTaskId(defaultTaskId && injectable.some((task) => task.id === defaultTaskId) ? defaultTaskId : injectable[0]?.id ?? '')
    setNote('')
    setError(null)
    setPending(false)
  }, [open, defaultTaskId, injectable])

  const estimatedChars =
    note.trim().length +
    nodes.reduce((sum, node) => sum + (node.type === 'text' ? node.data.content.length : 0), 0)

  const submit = async () => {
    if (!taskId || nodes.length === 0) return
    setPending(true)
    setError(null)
    try {
      await send({
        type: 'context.inject',
        payload: {
          taskId,
          nodeIds: nodes.map((node) => node.id),
          ...(note.trim() ? { note: note.trim() } : {}),
        },
      })
      onDone()
      onOpenChange(false)
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : '投喂失败')
    } finally {
      setPending(false)
    }
  }

  return (
    <Modal isOpen={open} onOpenChange={onOpenChange}>
      <Modal.Trigger className="sr-only" aria-hidden="true" tabIndex={-1}>
        投喂给任务
      </Modal.Trigger>
      <Modal.Backdrop>
        <Modal.Container>
          <Modal.Dialog>
            <Modal.Header>
              <Modal.Heading>投喂给任务</Modal.Heading>
            </Modal.Header>
            <Modal.Body>
              <div className="flex flex-col gap-3">
                <label className="flex flex-col gap-1 text-sm">
                  目标任务
                  <select
                    aria-label="目标任务"
                    className="rounded border border-separator bg-background p-2 text-sm"
                    value={taskId}
                    onChange={(event) => setTaskId(event.target.value)}
                  >
                    {injectable.map((task) => (
                      <option key={task.id} value={task.id}>
                        {task.title}（{task.status}）
                      </option>
                    ))}
                  </select>
                </label>
                <div className="text-xs text-muted">
                  节点 {nodes.length} 个 · 预计至少 {estimatedChars} 字；超预算会被服务端拒绝
                </div>
                <ul className="flex flex-col gap-1 text-xs">
                  {nodes.map((node) => (
                    <li key={node.id} className="flex justify-between gap-2">
                      <span>{nodeTitle(node)}</span>
                      <span className="text-muted">{node.type}</span>
                    </li>
                  ))}
                </ul>
                <label className="flex flex-col gap-1 text-sm">
                  投喂说明
                  <TextArea
                    aria-label="投喂说明"
                    value={note}
                    onChange={(event) => setNote(event.target.value)}
                    placeholder="为什么补这几个节点（可选）"
                    fullWidth
                  />
                </label>
                {error ? (
                  <p role="alert" className="text-sm text-danger">
                    {error}
                  </p>
                ) : null}
              </div>
            </Modal.Body>
            <Modal.Footer>
              <Button variant="tertiary" onPress={() => onOpenChange(false)}>
                取消
              </Button>
              <Button
                variant="primary"
                isDisabled={pending || !taskId || nodes.length === 0}
                onPress={() => void submit()}
              >
                投喂
              </Button>
            </Modal.Footer>
          </Modal.Dialog>
        </Modal.Container>
      </Modal.Backdrop>
    </Modal>
  )
}
```

注意：`TextArea` 已经有 `aria-label`，外层 `<label>` 只是视觉分组；测试用 `getByLabelText('投喂说明')` 命中 TextArea。
