# M6-2 Plan 4：web 任务详情与验收

> **For agentic workers:** REQUIRED SUB-SKILL: Use agent-harness:subagent-driven-development (recommended) or agent-harness:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 任务详情能看上下文时间线和累计 cost/turn；验收卡能用当前画布选择打回、verify 失败时通过需确认；手机只读。

**Architecture:** 新增 `ContextTimeline` 复用 `ContextSnapshotCard`；`TaskDetailPanel` 计算 usage 并传给 header/review；`ReviewCard` 用 `useAppStore.selectedNodeIds` 附带上下文，override 用内联确认块，不引入新弹窗体系。

**Tech Stack:** React 19、HeroUI v3、Tailwind 4、Zustand、Testing Library。

**Design sync:** 新增 UI 只使用 `DESIGN.md` token：`bg-background`、`border-separator`、`text-muted`、`border-warning`、`bg-warning/10`、`text-warning`。override 确认必须同时有警示文字和确认按钮，不能只靠颜色；Task 3 的组件测试验证。

**Commit strategy:** 每个 task 末尾提交；最后统一跑 `pnpm verify`。

**File structure:**

- `apps/web/src/features/tasks/ContextTimeline.tsx`：初始快照 + 注入列表。
- `apps/web/src/features/tasks/TaskDetailPanel.tsx`：时间线、usage、review usage。
- `apps/web/src/features/tasks/ReviewCard.tsx`：打回上下文、approve override。
- `apps/web/src/features/tasks/TaskDetailPanel.mobile.test.tsx`：手机只读。

```tsx
import type { ContextSnapshot } from '@baton/protocol'
import { Button } from '@heroui/react/button'
import { ContextSnapshotCard } from './ContextSnapshotCard'

export function ContextTimeline({
  snapshot,
  targetNodeId,
  knownNodeIds,
  onSelectNode,
}: {
  snapshot: ContextSnapshot | null
  targetNodeId?: string | null
  knownNodeIds?: ReadonlySet<string>
  onSelectNode?: (nodeId: string) => void
}) {
  return (
    <section className="flex flex-col gap-2">
      <ContextSnapshotCard snapshot={snapshot} targetNodeId={targetNodeId} />
      {(snapshot?.injections ?? []).map((injection) => (
        <section
          key={injection.seq}
          className="rounded-lg border border-separator bg-background p-3 text-xs"
        >
          <div className="flex items-center justify-between gap-2">
            <h4 className="text-sm font-medium">注入 #{injection.seq}</h4>
            <span className="text-muted">
              {new Date(injection.at).toLocaleString()} ·{' '}
              {injection.source === 'supervisor' ? '总管' : '你'}
            </span>
          </div>
          {injection.note ? <p className="mt-1 text-muted">{injection.note}</p> : null}
          <ul className="mt-2 flex flex-wrap gap-1">
            {injection.included.map((item) => {
              const missing = knownNodeIds ? !knownNodeIds.has(item.id) : false
              return (
                <li key={item.id}>
                  <Button
                    size="sm"
                    variant="tertiary"
                    isDisabled={missing || !onSelectNode}
                    onPress={() => onSelectNode?.(item.id)}
                  >
                    {item.title}
                    {missing ? '（已删除）' : ''}
                  </Button>
                </li>
              )
            })}
          </ul>
          <p className="mt-1 text-muted">
            {injection.included.length} 个节点 · {injection.chars} 字
            {injection.truncated ? ' · 已截断' : ''}
            {injection.dropped.length > 0 ? ` · 排除 ${injection.dropped.length} 个` : ''}
          </p>
        </section>
      ))}
    </section>
  )
}
```

```tsx
const approve = () => {
  action.run({
    type: 'review.decide',
    payload: {
      reviewId: review.id,
      decision: 'approve',

    },
  })
}
```

点击“通过”：

```tsx
onPress={() => {
```
