# M6-3 Plan 4：web 任务验收、报告与预算

> **For agentic workers:** 使用 `agent-harness:subagent-driven-development`（推荐）或 `executing-plans` 按 task 执行。

**Goal:** 让老板在任务详情里真正完成验收：看 AC、改 AC、看报告、看成本、改预算、二次确认；看板/移动端同步显示。

**Architecture:** 新增 `AcceptanceEditor`、`AcceptanceReport`、`BudgetEditor`、`BudgetCard`；`ReviewCard` 接收 acceptance/budget；`TaskDetailPanel` 组合；`TaskActions` 处理 `waiting_input(budget)`；看板/移动端只加摘要徽标。所有颜色/间距/圆角使用 `DESIGN.md` token。

**Tech Stack:** React 19、TanStack Query、Zustand、Tailwind 4、HeroUI v3、Testing Library、vitest。

**Commit strategy:** 每个 task 末尾一次 commit。

**Design sync:** 每个 UI task 开始前读根目录 `DESIGN.md`；禁止硬编码 hex/字号/圆角/间距；新增徽标/颜色先改 addendum。状态不能只靠颜色，必须有文字或图标。
