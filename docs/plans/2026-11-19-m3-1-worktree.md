# M3-1 Slice 2：worktree 隔离实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans. 每任务结束提交，不 push。
>
> **实现位置校正**：spec §7.3 写“调度器在 queued→running 前创建”。当前 `runtime/scheduler.ts` 的 `pump()` 是同步的，直接改会造成并发与事务复杂度；本计划把创建放在 `session-runner.start` 的适配器启动之前（状态已是 `running`，但 session 尚未开始）。可观察行为与 spec 一致：创建失败 → `failed`，可 retry。

**Goal:** 任务可选独立 worktree；verify、diffStat、diff 捕获都在工作树内执行；并行任务互不污染；清理可显式执行且保留分支。

**Architecture:** 新增 `workspace/worktree.ts` 端口式模块；`task-service` 放开 `workspaceMode` 并校验 git；`session-runner.start` 启动适配器前确保工作树；verify runner 统一用 `task.worktreePath ?? main`；REST 提供清理与 workspace 能力查询；boot 只 prune 与对账。

**Tech Stack:** execa、Drizzle/SQLite、Fastify 5、React 19、HeroUI v3、vitest、Playwright。

```ts
const TASK_ID = /^[A-Za-z0-9_-]+$/

export function worktreePathFor(dataDir: string, taskId: string): string {
  if (!TASK_ID.test(taskId)) throw new Error('invalid_task_id')
  return join(dataDir, 'worktrees', taskId)
}

export async function createWorktree(input) {
  if (!TASK_ID.test(input.taskId)) return { ok: false, reason: 'invalid_task_id' }
  if (!(await isGitRepo(input.workspacePath))) return { ok: false, reason: 'not_a_git_repo' }
  const path = worktreePathFor(input.dataDir, input.taskId)
  const branch = branchFor(input.taskId)
  if (input.existingPath && existsSync(input.existingPath)) {
    return { ok: true, path: input.existingPath, branch }
  }
  mkdirSync(dirname(path), { recursive: true })
  const hasBranch = await branchExists(input.workspacePath, branch)
  const args = hasBranch
    ? ['-C', input.workspacePath, 'worktree', 'add', path, branch]
    : ['-C', input.workspacePath, 'worktree', 'add', '-b', branch, path, 'HEAD']
  const result = await execa('git', args, { reject: false })
  if (result.exitCode !== 0) return { ok: false, reason: 'worktree_create_failed' }
  const real = realpathSync(path)
  if (!real.startsWith(realpathSync(input.dataDir) + sep)) {
    await removeWorktree({ workspacePath: input.workspacePath, path })
    return { ok: false, reason: 'worktree_escape' }
  }
  return { ok: true, path, branch }
}
```

`removeWorktree` 用 `git worktree remove --force <path>`，不删分支；`pruneWorkspace` 用 `git worktree prune`。

```ts
let workspacePath = input.workspacePath
if (task.workspaceMode === 'worktree') {
  const prepared = await createWorktree({
    dataDir: deps.dataDir,
    workspacePath: input.workspacePath,
    taskId: task.id,
    existingPath: task.worktreePath,
  })
  if (!prepared.ok) {
    failTask(task.id, input.sessionId, appError('worktree_unavailable', prepared.reason))
    return

  workspacePath = prepared.path
  if (task.worktreePath !== prepared.path) updateTaskWorktreePath(deps.db, task.id, prepared.path, deps.now())
}
run = await adapter.start({
  prompt: task.prompt,
  cwd: workspacePath,
  permissionMode: 'manual',
  policy: input.policy,
  workspaceTrust: input.workspaceTrust,
  bypassPermissions: input.bypassPermissions,
})
```
