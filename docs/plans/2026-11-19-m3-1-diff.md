- [ ] **Step 2: 跑测试确认失败**

Run: `pnpm --filter @evanfang0054/baton exec vitest run test/verify-diff.test.ts`
Expected: FAIL（模块不存在）

- [ ] **Step 3: 实现**

`diff.ts` 拆成四个 helper：

1. `gitNumstat(workspacePath)`：`git -C <path> diff --numstat --find-renames HEAD`，解析 `insertions/deletions/path`；`-` 视为 binary。
2. `gitUntracked(workspacePath)`：`git -C <path> status --porcelain=v1 -z`，收集 `??` 路径。
3. `readPatch(workspacePath, file)`：tracked 用 `git diff --no-color --no-ext-diff --unified=3 HEAD -- <path>`；untracked 用 `git diff --no-index -- /dev/null <path>`（exitCode 1 视为有差异）；binary 返回空 patch。
4. `truncateFiles(files)`：单文件 patch 超 128KB 截断该文件；合计超 512KB 停止追加；置 `truncated`。

```ts
const MAX_FILE_PATCH = 128 * 1024
const MAX_TOTAL_PATCH = 512 * 1024

export async function captureDiff(workspacePath: string, now: () => number): Promise<DiffSnapshot> {
  const inside = await execa('git', ['-C', workspacePath, 'rev-parse', '--is-inside-work-tree'], { reject: false })
  if (inside.exitCode !== 0) return { v: 1, capturedAt: now(), baseRef: 'HEAD', truncated: false, files: [] }

  const files = [...(await gitNumstat(workspacePath)), ...(await gitUntracked(workspacePath))]
  const withPatches = await Promise.all(files.map((file) => readPatch(workspacePath, file)))
  return { v: 1, capturedAt: now(), baseRef: 'HEAD', ...truncateFiles(withPatches) }
}
```
